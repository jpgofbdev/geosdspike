GeoSD — Fond de carte PMTiles hors connexion

Expérimentation isolée, séparée du projet GeoSD de production. Voir README-spike.md dans le dépôt pour le détail complet.

⚠ Ce dépôt est jetable : soit le spike est concluant et nourrit une décision documentée dans GeoSD, soit il est abandonné sans laisser de trace dans le projet réel. Ne pas s'appuyer dessus pour un usage terrain réel.

Ce qui est testé ici

La page de saisie terrain (geosd-terrain-saisie.html) est portée telle quelle depuis GeoSD, avec une seule modification : le sélecteur de fond de carte propose désormais une entrée supplémentaire, « Fond PMTiles (test) », à côté d'OpenStreetMap, du Plan IGN et de l'Orthophoto IGN.

Ce fond charge le fichier CVL.pmtiles (région Centre-Val de Loire) via la bibliothèque pmtiles et leafletRasterLayer. Il apparaît dans le switcher quelques instants après le chargement de la page (chargement paresseux de la bibliothèque).

Comment tester

  1. Ouvrir la page de saisie ci-dessous.
  2. Choisir un territoire (ou passer).
  3. Ouvrir le sélecteur de fonds de carte (en haut à droite) et cocher « Fond PMTiles (test) ».
  4. Vérifier l'affichage, puis cliquer sur la carte pour confirmer que la saisie de point (popup + formulaire) fonctionne toujours par-dessus ce fond.
  5. Repasser en mode avion une fois le fond chargé, et réessayer les mêmes actions pour évaluer le comportement hors connexion.

Points à vérifier (voir README-spike.md)

  • Rendu correct du fond PMTiles une fois sélectionné.
  • Cohabitation sans conflit avec la couche de marqueurs.
  • Comportement en coupure réseau effective (mode avion).
  • Poids / mode de chargement compatibles avec un usage tablette.
  • Fidélité visuelle par rapport au prototype MapLibre initial (offline-map-lab).
